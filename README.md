# Termux Custom Setup by Unknown-Desert

Termux Features:
- 🕵️ Fake Offline Layer
- 🛡️ Safe DNS
- 🚫 Block ADS & Malware
- 🔒 Anti-DPI
- 📊 Cool Info
- 🔑 Password Profiles

## 📥 How to Install

Clone
    
```bash
git clone https://github.com/Unknown-Desert/Termux.git
```

Open Folder

```bash
cd Termux
```

Run Installer

```bash
sh install.sh
```

Back Home

```bash
cd
```

Run Custom (termux.sh)

```bash
sh termux.sh
```
