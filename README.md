# Termux Custom Setup by Unknown-Desert

Termux Features:
- 🕵️ Fake Offline Layer
- 🛡️ Safe DNS
- 🚫 Block ADS & Malware
- 🔒 Anti-DPI
- 📊 Cool Info
- 🔑 Password Profiles

## 📥 How to Install

Clone
    
```bash
git clone https://github.com/Unknown-Desert/Termuxstyle.git
```

Open Folder

```bash
cd Termuxstyle
```

Run Installer

```bash
bash install.sh
```

Fill:

- Custom Banner Name
- Custom Username
- Custom Password
- Custom Password Hint
- Custom Short Call

How To Uninstall:

```bash
cd Termuxstyle
```

Set Default or Delete:

```bash
bash uninstall.sh
```
